AssignKit

Set it once. Everyone gets their own paper.

AssignKit is for class assignments. A lecturer writes the questions, the system deals out a different set to each student, and the marking is done by the time the deadline passes.

  • Different sets, same standardStudents sitting next to each other are not looking at the same questions.
  • Marked as they goMultiple choice and short answers are graded straight away, with no waiting on anyone.
  • Timed on the serverTimers and attempts are kept by the server, so refreshing the page doesn't buy anyone extra time.
